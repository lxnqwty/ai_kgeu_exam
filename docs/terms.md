# Мини-словарь терминов

Краткий словарь к курсу **Искуственный Интеллект**.

| Термин | Кратко |
|---|---|
| **ИИ (AI)** | методы, позволяющие компьютеру решать «интеллектуальные» задачи |
| **ML** | алгоритмы, которые учатся закономерностям на данных |
| **Deep Learning** | ML на основе многослойных нейронных сетей |
| **Модель** | функция с настраиваемыми параметрами, делающая предсказания |
| **Признак (feature)** | входная характеристика объекта |
| **Метка (label, target)** | правильный ответ, который нужно предсказать |
| **Тензор** | многомерный массив чисел, основной тип данных в PyTorch |
| **Регрессия** | предсказание числа |
| **Классификация** | предсказание класса |
| **Нейрон** | вычисляет `f(w·x + b)` |
| **Вес (weight)** | множитель при входе, обучаемый параметр |
| **Смещение (bias)** | прибавляемое число, обучаемый параметр |
| **Функция активации** | добавляет нелинейность (Sigmoid, ReLU, Softmax) |
| **Слой** | группа нейронов, работающих параллельно |
| **Полносвязный слой** | каждый нейрон связан со всеми входами (`nn.Linear`) |
| **Скрытый слой** | слой между входом и выходом |
| **MLP** | сеть из нескольких полносвязных слоёв с активациями |
| **Прямой проход (forward)** | вычисление предсказания от входа к выходу |
| **Функция потерь (loss)** | мера ошибки модели |
| **Градиент** | направление и величина изменения весов для уменьшения потерь |
| **Оптимизатор** | обновляет веса по градиентам (SGD, Adam) |
| **Learning rate** | размер шага обновления весов |
| **Эпоха** | один полный проход по датасету |
| **Батч** | порция данных для одного шага обучения |
| **Переобучение** | модель хорошо работает на train, плохо на новых данных |
| **Гиперпараметр** | настройка, которую задаёт человек (`lr`, число слоёв и т. д.) |
